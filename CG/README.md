# Computational Geometry — Midterm

English preparation based on the nine supplied COT4521/5520 lecture PDFs.

- Seven topic pages with notes, worked examples, and conceptual checks.
- 132 multiple-choice questions with explanations and source page references.
- 88 fill-in-the-blank exercises with hints and accepted alternatives.
- A 30-question mixed practice exam and worked answer key.
- A study plan, formula reference, source map, and exam logistics.

Open `CG/index.html` through an HTTP server (for example, `python3 -m http.server 8000` at the repository root). JSON and Markdown are fetched by the browser. Start with the study notes tab, then quiz and fill-in-the-blank practice. Progress and theme are stored locally in your browser under CG-specific keys.

The layout, JSON schemas, note filenames, theme, and mastery/session behavior follow the existing FSWT subject. Its English interface and bundled Markdown parser are reused within CG; other subjects are unchanged. Original lecture PDFs are referenced, not redistributed. No external APIs or account are required.

Run `python3 CG/scripts/validate.py` to validate content contracts, local assets, source ranges, counts, and exercise coverage. See the source guide for conventions and supplemental clarifications.
